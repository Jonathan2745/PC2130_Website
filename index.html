Start with an example, then edit the expression. Apply it when you’re ready.

ψ(x, y, z, t) =

Enter the right-hand side only, using * to multiply and ^ for powers: exp(i*x). Buttons insert at the cursor or wrap selected text. “ψ Gaussian” inserts an envelope you can edit.

This plots the ψ you supply. To animate a custom state, include its time dependence using t; the editor does not solve its evolution for you.

Default analytic Gaussian loaded.
Available equation variables

x, y, z, t, i, m, hbar, sigma, x0/y0/z0, px0/py0/pz0, gx/gy/gz, tau, N0, xg/yg/zg, p02, g2, gdotr, xc/yc/zc, pxt/pyt/pzt, sigmaT.

The editor directly controls the position-space visualization. The momentum and energy views remain analytic diagnostics for the Gaussian parameters; arbitrary edited ψ is not Fourier-transformed or numerically propagated.
